# Kubernetes Labs

A hands-on Kubernetes learning repository focused on real-world troubleshooting, production concepts, and interview preparation.

The labs are organized into progressive levels, starting with Kubernetes fundamentals and moving toward advanced operational topics. Each module contains practical exercises, manifests, debugging scenarios, and solutions to build confidence with day-to-day Kubernetes administration.

## Level 1 – Core Fundamentals

* Pod Troubleshooting
* Deployments & Rollouts
* Services & DNS
* Health Probes
* Resource Limits & Scheduling
* RBAC
* Ingress
* Logging & Debugging

## Level 2 – Advanced Topics

* ConfigMaps & Secrets
* Persistent Volumes & Storage
* Node Troubleshooting
* Namespaces & Contexts
* Horizontal Pod Autoscaler (HPA)
* Network Policies
* Taints, Tolerations & Affinity

## Goal

Build strong Kubernetes fundamentals through practical labs that mirror real production scenarios, helping with DevOps, SRE, Platform Engineering, and Kubernetes certification preparation.
